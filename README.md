# Tools

MCP extension `com.example.source-mcp`. Edit `mcp.json`, run `grain-ext doctor`, then `grain-ext pack`.

Grain owns connection identities, enablement and OAuth consent. Never put credentials, client IDs, headers or server-launch commands in this descriptor. No Grain JavaScript SDK or Node build is required. `grain-ext dev` applies only to native tool projects. Store publishing remains provisional.
