# Tools

Grain extension id: `com.example.source-native`

## Develop

1. Install Node.js and run `npm install`.
2. Run `npm run build` once.
3. Run `grain-ext doctor`.
4. Enable Developer mode in Grain and add this folder as an unpacked extension.
5. Run `grain-ext dev` for incremental builds and hot reload.

Edit `src/main.ts`; `grain.d.ts` is generated from the Grain SDK. `DESCRIPTION.md` is reserved for user-facing listing text; README is developer documentation. Catalog/media migration remains provisional.
